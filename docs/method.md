# Pairwise method

Blocking is a deterministic candidate-reduction step, not a model decision. Exact, normalized, overlap, length-ratio, and sorted-neighbourhood blockers compose; labeled true pairs expose estimated blocking recall and dropped matches.

Within candidates, normalized identity and configurable overlap extremes resolve easy pairs. Only the uncertain band reaches the provider. Packing raises throughput but puts unrelated pairs in the same state and may reduce judgment quality. Cache keys sort the two content hashes, so direction does not repurchase a judgment.

Clustering uses explicit complete or average linkage. It never assumes transitivity: a triangle with exactly two positive edges is returned as a conflict.
